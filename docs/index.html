Classes

AppCanvas

Represents a canvas that supports basic drawing operations such as circles, rectangles, lines, and text with customizable colors. Implements the BOOSE.ICanvas interface.

AppCircle

The app circle class is responsible for calling the unrestricted version of the circle method it inherits from the commandoneparameter class the radius of the circle is provided as a parameter

AppCommandFactory

The AppCommandFactory class is responsible for creating specific command objects based on the provided command type. Inherits from the BOOSE.CommandFactory class.

AppMoveTo

The AppMoveTo class is responsible for moving the position of the pen on the canvas. It inherits from the CommandTwoParameters class where the x and y values are supplied as parameters.

AppRect

The appRect class is responsible for calling the unrestricted version of the rect command it inherits the command two parameters class the height and width are provided as parameters

Form1

The main form of the application. It initializes the canvas, command factory, stored program, and parser, and provides functionality for interacting with the canvas via user input.
